## 3. 소스 및 구조 분석 요약

1. **레이아웃 및 CSS 구조**
   - `width=1400` 고정폭 기반으로 설계되어 현재 고해상도 모니터 및 태블릿/모바일에서 반응형 대응이 불가함.
   - 서브페이지 상단 타이틀 아래 2차 메뉴가 **가로 탭(`.tab` 형태)**으로 배치되어 있으며, GNB 드롭다운 메뉴와 중복 노출됨.
2. **레거시 HTML / JavaScript**
   - `euc-kr` 인코딩과 `XHTML 1.0 Strict` 선언을 사용하나, 내부 마크업에는 `<font>` 태그(다수 진료 페이지), `<table>` 레이아웃, 인라인 `onclick` 이벤트 등이 혼재되어 웹 표준/접근성이 낮음.
   - `index.html`에 IE 구버전 전용 API인 `showModalDialog` 호출 코드가 남아 있음.
   - `jquery-1.11.1` 및 `jquery.cycle.all.js` 등 유지보수가 중단된 구형 라이브러리에 의존.
3. **콘텐츠 및 미디어 구성**
   - **텍스트 빈약 / 이미지 의존 페이지 다수**: `교육자 박천진(hp_12)`, `귀두확대술(c3_0101)`, `조루증의 치료(c6_0301)`, `발기부전치료(c4_0301)` 등은 본문 텍스트가 거의 없고(공통 영역 제외 시 극소량) 이미지·유튜브 영상 위주로 구성되어 검색엔진(SEO) 크롤링에 불리함.
   - **YouTube 영상 적극 활용**: 다수의 진료 페이지 및 VIDEO GALLERY에 YouTube `iframe`이 삽입되어 있음.
4. **정보구조(IA) 불일치 요소**
   - `정관수술` 대메뉴 클릭 시 `c5_0101.html`로 이동하지만, 상단 탭은 `무도정관수술(c5_0201)`·`미세정관복원수술(c5_0301)` 2개만 표시됨.

## 4. 리뉴얼 시 핵심 개선 포인트 (To-Be 방향성)

1. **반응형 웹 통합 + HTTPS/UTF-8 전환**: PC(`www`)와 모바일(`m`) 분리 운영을 반응형 웹으로 통합하고, HTTPS 및 UTF-8 전환으로 보안·검색 신뢰도 확보.
2. **IA(메뉴 구조) 재정비**:
   - 단일 메뉴(`음경임플란트`, `포경수술`)와 유사 진료(`성기능장애`, `남성성형`)의 계층 구조 통합·재배치.
   - `공지사항`, `FAQ`, `비용문의` 등 고객 접점 메뉴의 접근성 일원화.
3. **콘텐츠 텍스트화(SEO/AEO 최적화)**: 통이미지 위주의 시술 설명을 시맨틱 HTML 텍스트 + 고화질 이미지/인포그래픽으로 분리해 검색 노출 및 가독성 강화.
4. **상담/예약 전환율(CRO) 개선**: 구형 게시판/예약 폼(`rev.html`)을 모바일 친화적인 간편 상담·예약 UI(카카오톡/전화/간편예약 플로팅)로 개편.
